Detailed Description

LittleFS on a remote nbd export opened with NBDClient. After begin() the files are accessed with the littlefs C API (lfs_file_open() etc.) using lfs().

The NBDClient must be connected before begin() and must outlive this object. A network disk does not need to be erased, so the erase callback does nothing. Each cache miss is a network round trip: the caches have the size of a block.
