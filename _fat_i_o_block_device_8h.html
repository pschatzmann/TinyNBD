Detailed Description

BlockDevice adapter for a TinyFATFS IO driver. Any TinyFATFS drive (RAM, SD, SDMMC, SPI, file, ...) can be exported through NBD with it.

Needs the TinyFATFS library (https://github.com/pschatzmann/TinyFATFS) on the include path (the directory that contains driver/IO.h). This header is not included by NBD.h.
