Detailed Description

Implements the nbd client side of the protocol (fixed newstyle handshake with NBD_OPT_EXPORT_NAME, and the transmission phase with simple replies). All calls are synchronous and must be made from the Arduino loop().

Usage:

WiFiClient wifi;
NBDClient nbd(wifi);
if (nbd.connect("192.168.1.10", NBD_DEFAULT_PORT, "ram")) {
uint8_t buf[512];
nbd.read(0, buf, sizeof(buf));
nbd.disconnect();
}
