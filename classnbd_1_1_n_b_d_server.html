Detailed Description

template<class ServerT, class ClientT = decltype(internal::declval<ServerT&>().accept())>
class nbd::NBDServer< ServerT, ClientT >

nbd server for any Arduino Server which provides accept() (e.g. WiFiServer, NetworkServer, EthernetServer). Call loop() from the Arduino loop().

Template Parameters
ServerTArduino server class
ClientTclient class returned by ServerT::accept()
