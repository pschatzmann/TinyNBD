Detailed Description

Exports a TinyFATFS IO driver as a sector based BlockDevice.

Dependency: this class requires the TinyFATFS library (https://github.com/pschatzmann/TinyFATFS). Its src folder must be on the include path, so that driver/IO.h and ff/ff.h resolve. TinyFATFS is not bundled with this library and is not included by NBD.h.

  • Sector size and count are reported by the driver (GET_SECTOR_SIZE and GET_SECTOR_COUNT) and cached when the device is initialized.
  • Unaligned access is handled by SectorBlockDevice (read-modify-write).
  • flush() uses CTRL_SYNC.
  • trim() uses CTRL_TRIM for the full sectors inside the range. If the driver does not support trim (RES_PARERR), the request succeeds without action.
  • isReadOnly() reports STA_PROTECT of the driver, and writes are refused when FF_IO_USE_WRITE is 0.

The driver must outlive this object. Call begin() (done by NBDServer::begin()) before using the device, or the first size query initializes it.
